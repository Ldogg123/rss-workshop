# Third-party notices

The files in this directory preserve upstream license and copyright notices.
Each applies to its named component, not automatically to RSS Workshop's
original code. The application's own LICENSE remains separate. Some notices
cover development tools or source-only assets not linked into the executable;
including their text does not make them runtime dependencies.

`modernc.org_libc@v1.75.6_GENERATED-HEADER-NOTICES` preserves additional notices
from Linux/amd64 and Linux/arm64 generated UUID and system-type declarations.
The LGPL-2.1, GPL-3, and GCC Runtime Library Exception texts accompany those notices;
the module's main license and other third-party notices also remain here.

Source locations and exact versions are recorded by the filenames and the
repository's `docs/dependencies.md` and `docs/licensing.md`. The modernc source
is at https://gitlab.com/cznic/libc/-/tree/v1.75.6. The Go time-zone data provenance
is preserved in `Go-time-zone-data-README`.

Debian/Chromium package notices in browser images additionally live in
`/usr/share/doc/<package>/copyright` and `/usr/share/common-licenses`.
Public prebuilt-image releases must provide their corresponding source
materials as described by the release's source index and download links.
